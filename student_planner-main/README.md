# Student Planner

A modular, menu‑driven command‑line planner built in Python.  
Designed for students to manage tasks, events, reminders, and personal preferences through a clean and intuitive interface.

---

## Features

### **Account System**
- Create and log into accounts  
- Passwords securely hashed using SHA‑256  
- User‑specific data stored in JSON  

### **Task Management**
- Add new tasks  
- Edit existing tasks  
- Delete tasks  
- Mark tasks as complete  
- Sort tasks  
- Search tasks  

### **Events & Reminders**
- Add events with dates  
- Add reminders  
- Stored per‑user  

### **User Preferences**
- Theme (light/dark)  
- Layout options  
- Density settings
